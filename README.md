# TeaPoly.github.io

A personal Jekyll site for Lucky Wong.

The current visual direction is intentionally minimal and editorial, with strong inspiration from [miskov.ee](https://miskov.ee/). The site aims for a quiet, spacious layout with restrained typography, generous whitespace, and a polished, design-forward resume experience.

## What this site is

This site is organized around three primary areas:

- `Resume` — the default landing page, focused on professional background and core strengths
- `Cave` — a compact writing and archive space with articles and hobbies
- `Hobbies` — a more visual extension of personal interests, including books, music, films, and fashion

## Design goals

- Keep the interface minimal and calm
- Use whitespace as a core design element
- Let typography carry most of the visual weight
- Keep article lists compact and easy to scan
- Present hobby content as curated visual modules
- Maintain a consistent, understated tone across pages

## Current page structure

### `Resume`

The default homepage now opens on the resume view. It is structured into three clear sections:

1. A large opening statement
2. A short background summary including school and work experience
3. Two content blocks for `Core areas` and `Work style`

The intent is to mirror the spatial rhythm and confidence of the reference inspiration while keeping the content specific to speech, audio, and embedded systems work.

### `Cave`

The `Cave` page contains a compact article list and a hobby section.

- The article list defaults to the latest 4 posts
- Category pages exist for `Tech`, `Life`, and `All`
- The fashion section uses brand logos for clearer recognition

### `Homepage behavior`

The root `/` now redirects to `/about/`, so the resume page is the primary landing experience.

## Tech stack

- [Jekyll](https://jekyllrb.com/)
- HTML and Liquid templates
- Sass for styling

## Notes

This repository was originally based on the Daktilo Jekyll theme, but the current site has been heavily reshaped to fit a more editorial, portfolio-like layout.
